🧠 Главный инсайт
В Python Класс — это тоже объект (экземпляр метакласса type).

    Он создается в памяти в тот момент, когда интерпретатор доходит до строки class Name:.
    До этой строки объекта-класса не существует.

❌ Проблема: NameError
Если класс A использует класс B в аннотациях, а B описан ниже:
python

class A:
    def __init__(self, link: B): # Ошибка! Объект-класс B еще не создан
        pass

class B:
    pass

Use code with caution.
✅ Решение 1: Кавычки (Old School)
Указание типа строкой. Python не ищет объект сразу, а просто хранит строку.
python

class A:
    def __init__(self, link: "B"): # Работает, но выглядит грязно
        pass

Use code with caution.
✅ Решение 2: Future Annotations (Modern)
Добавление from __future__ import annotations в самую первую строку файла.

    Что делает: Автоматически превращает все аннотации в строки.
    Результат: Ошибки нет, код чище, импорты работают быстрее.

🔍 Что внутри (Dunder методы)

    __annotations__: Словарь, где хранятся подсказки типов.
        Без магии: Содержит ссылки на живые объекты-классы.
        С магией: Содержит просто строки (текст).
    Где живет: У классов, функций и модулей (но обычно не у экземпляров).

🛠 Как «оживить» типы?
Если библиотеке (например, Pydantic) нужно превратить строки обратно в классы, используется:
inspect.get_type_hints(obj)
💡 Запомнить: Если видишь NameError при объявлении типов — либо двигай классы выше, либо добавь from __future__ import annotations.
